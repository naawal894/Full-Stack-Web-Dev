## 📚 Course Topics & Tech Stack

This repository tracks learning across a modern full-stack web development stack:

- **Frontend**: **React** (HTML5, CSS3, JavaScript/TypeScript, Component Architecture, State Management).
- **Backend**: **NestJS** (Modular Architecture, Controllers, Services, Dependency Injection, REST APIs, DTOs, Guards).
- **Database**: **PostgreSQL** (Relational Database Design, SQL Queries, Migrations, ORMs/TypeORM/Prisma).
- **DevOps & Workflows**: Git version control, environment configuration, and deployment workflows.

## 🚀 Getting Started

To explore or run any code from this repository locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/naawal894/Full-Stack-Web-Dev
   ```

2. **Navigate into the repository:**

   ```bash
   cd Full-Stack-Web-Dev
   ```

3. **Navigate into any specific coursework directory:**
   ```bash
   cd <directory-name>
   ```
