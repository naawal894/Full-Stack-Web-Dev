# Task 4 — IEEE Paper Template

An **IEEE conference paper template** rendered in HTML & CSS only.

## Features

- Authentic IEEE two-column academic layout
- **Times New Roman** serif font throughout (standard for IEEE papers)
- Full paper structure:
  - Title and author block (centered, full-width)
  - Abstract with keywords
  - Two-column body with numbered sections (I–VI)
  - Subsections with italic headings
  - Data table (Table I) with proper IEEE formatting
  - Numbered references list
- Justified text with hyphenation
- Print-ready — outputs clean on paper
- Responsive — falls back to single column on mobile

## Paper Topic

**"Impact of Artificial Intelligence on Modern Software Engineering Practices: A Comprehensive Survey"**

## Sections

1. Introduction
2. Related Work
3. Methodology (includes Table I)
4. Results and Discussion
5. Challenges and Limitations
6. Conclusion
7. References (15 citations)

## Files

| File | Purpose |
|------|---------|
| `index.html` | Paper content and structure |
| `style.css` | IEEE-standard formatting, two-column layout, print styles |
