# Task 3 — Portfolio

Personal portfolio/resume page for **Nawal Fateh**, built with HTML & CSS only.

## Features

- **Full-width header** — Name, title, contact links (email, GitHub, LinkedIn, portfolio site), and profile photo in the top-right corner
- **Two-column body** — Skills sidebar on the left, experience/education/projects on the right
- Skills organized by category (Client-Side, Server-Side, Systems & DevOps, AI/ML) with tag chips
- Focus area progress bars (Machine Learning, Full-Stack Web, Systems Programming, Data Science)
- Experience section with NASTP internship, AI Research Assistant role, and independent projects
- Education and project listings
- Print-friendly and responsive
