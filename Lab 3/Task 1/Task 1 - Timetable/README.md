# Task 1 — Class Timetable

Recreated the **BSCS-V-B (Shift-I)** weekly class timetable using HTML & CSS only.

## Features

- Clean, light institutional design with color-coded courses
- Each course has a distinct accent color (Web Dev, AI, Algorithms, OS, Linear Algebra, Management)
- Lab sessions span multiple time slots using `colspan`
- Color-coded day sidebar with left-border accents
- Legend at the bottom for quick course identification
- Responsive — scrollable on smaller screens

## Files

| File | Purpose |
|------|---------|
| `index.html` | Table structure with all course data |
| `style.css` | Light theme styling, colors, and responsiveness |

## Courses Covered

- Full Stack Web Development
- Linear Algebra
- Artificial Intelligence (+ Lab)
- Design & Analysis of Algorithms
- Operating Systems (+ Lab)
- Introduction to Management
